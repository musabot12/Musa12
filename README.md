🚀 INSTALLATION

1️⃣ Clone Repository

git clone https://github.com/musabot12/musa-bot.git

2️⃣ Enter Folder

cd musa-bot

3️⃣ Install Dependencies

npm install

4️⃣ Start Bot

npm start


---

⚙️ RUN COMMANDS

Normal Start

node index.js

Development

npm run dev

Production

npm run prod
